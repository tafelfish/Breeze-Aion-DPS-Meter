## 1.3.0 Patch Notes

### DPS Meter & Encounter Analysis

- Added up to **three additional meters** for damage, healing, damage taken or buffs, with independent settings and appearance.
- Added **Copy Main Style** to quickly match additional meters to the main meter.
- Added an option to **hide the upper meter section**, including the encounter summary and boss information.
- Added timed training sessions with support for **Training Scarecrow** and **Melee Training Scarecrow**.
- Added encounter comparisons, selectable time ranges and buff activation damage analysis.
- The camera button now **copies encounter images to the clipboard**, preserving the selected metric, skill breakdown and name privacy settings.
- Improved exported image spacing and layout.

### Restored Healing (Experimental)

- Healing meters now display **verified HP restored**, excluding overhealing.
- Improved matching for multiple heals that correspond to a fresh HP increase.
- Unclear healing remains **Unknown**, with partial measurements and coverage clearly labelled.
- Reported healing remains available in encounter analysis.

*Measurement coverage is still limited and under investigation. Restored-healing totals may be incomplete.*

### Edit UI & Window Controls

- Organised Edit UI into **collapsible sections**, with Expand All and Collapse All controls.
- Added **named layout profiles**.
- Added independent anchored and unanchored styles for the **Pet Tracker** and **Cloud Merchant**, including click-through mode, transparency, colours and spacing.
- Added shortcuts to **show/hide** and **anchor/unanchor** individual windows or all windows together.
- Added previous-layout recovery and **Bring Onto Screen** controls.
- Fixed cases where window size or position changed after restarting, updating or using Edit UI.
- Improved support for layouts positioned near the bottom of the screen.

### Pet Tracker & Cloud Merchant

- Improved pet-tracker recovery after connection or capture interruptions, using clearly labelled **estimated progress** for the confirmed character.
- Estimated completions now briefly display **Estimated Complete**, then leave the tracker.
- Fresh collection syncs verify estimated completions and send a correction notification when more souls are needed.
- Added pet icons to the Pets menu.
- Corrected Odyle spider names and collection matching.
- Added an option to **hide the pet tracker inside dungeon instances**.
- Improved merchant offer parsing and recovery.
- Merchant offers can use clearly labelled **last-recorded collection progress** while sync recovers.

### Crafting Tree (Experimental)

- Added an interactive crafting tree with marketplace prices, recipe alternatives and buy/craft choices.
- Added **Perfect, Average and 99% planning scenarios**.
- Owned materials and intermediate items now **reduce the remaining cost of the final item**.
- Improved tree navigation, item cards and material quantities.
- Missing prices and unsupported success rates remain clearly identified.

### PvE Gear Guidance

- Added editable stat priorities for damage, tanking, healing and support.
- Added desired stats and optional minimum values, saved per character and equipment slot.
- Added compact labels for matching stats and potential reroll candidates.
- Unverified stat availability remains clearly indicated.

### Notifications & Buff Reminders

- Added **Nyerk!** as the default boss, event and pet-completion sound, with the previous sound still selectable.
- Added custom **MP3, WAV and OGG** sounds per notification type and individual alert.
- Added separate volume controls, playback limits and temporary audio mute.
- Shortened boss and event notifications and reduced unused toast space.
- Added an option to continue notifications while Aion 2 is closed.
- Improved active-buff handling during dungeon transitions.
- Unknown buff states no longer automatically trigger inactive-buff warnings.
- Added distinct menu icons for Boss Timers and Buff Reminders.

### Settings, Updates & Reliability

- Added settings export and import for preferences, hotkeys, layouts, reminder selections, gear targets and custom sounds.
- Update notices now display the **latest available version and its patch notes**.
- Improved capture buffering during traffic bursts.
- Added clearer window-status information and troubleshooting reports.
