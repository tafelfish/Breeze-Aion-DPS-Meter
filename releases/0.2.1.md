# Breeze Aion DPS Meter 0.2.1 Preview

Removes the incomplete Cube layer from the interactive map. The previous dataset showed only 206 markers and did not cover the full set of possible spawn locations.

- Removed Cube pins, the layer toggle, legend entry, and Cube color setting.
- Old saved Cube selections are ignored safely.
- Other map markers, layer preferences, and saved collection progress are preserved.

Download and run **Aion2Meter_0.2.1_x64-setup.exe**, or install the local update when available. Close the running meter normally before running setup manually. Existing settings and encounter history are retained.

This remains a prerelease preview. GitHub automatic update checks follow production releases only; previews are manual downloads. The existing local update folder can offer this preview through the app.

The Windows x64 installer is unsigned. Windows may show an unknown publisher or SmartScreen warning. See the [installation requirements](https://github.com/tafelfish/Breeze-Aion-DPS-Meter#download-the-preview). The attached `latest.json` contains the installer size and SHA-256.
