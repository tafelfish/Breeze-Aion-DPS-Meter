**Aion 2 Companion — Version 1.3.1**

**Server Ping**

- Added a live server connection ping display, available on the DPS meter or in a separate transparent window.
- The separate window defaults to the bottom-left of Aion 2’s monitor and appears while the game is focused.
- Customize placement, text size and visibility in Edit UI.
- Color indicators: **green up to 75 ms**, **yellow from 76–125 ms**, and **red above 125 ms**.
- Added optional **60-second ping history**.
- Unavailable measurements display a dash.

**Edit UI & Settings**

- Added **Undo and Redo** for layout and settings changes during an editing session.
- Added **settings search**, with direct navigation to matching controls, including collapsed sections.

**Notifications**

- Old queued notifications now expire instead of appearing in a delayed backlog.

**DPS Meter**

- Removed the unnecessary **“Boss fight”** label.
