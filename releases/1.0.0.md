# Breeze Aion DPS Meter 1.0.0

The first production release brings the live meter and Companion together in one Windows application, with independently controlled windows and saved layouts.

## Included

- Automatic encounter tracking with damage, healing, damage taken, skill breakdowns, timelines, CPM/HPM, and recorded buff uptime.
- Dungeon-run encounter history with per-boss details, run totals, and newest-first ordering.
- Customizable full and compact meter layouts, class colors, transparency, columns, click-through anchoring, show/hide shortcuts, and game visibility rules.
- Player privacy settings, optional combat power and item level, saved encounter profile values, and opt-in comparisons against your own previous successful kill.
- Character profiles with portraits, equipment details, skill icons, speciality hover descriptions, and compact character/skills images with Copy and Save PNG actions.
- The last character sheet stays available through navigation, disconnects, and restarts until another character is opened or detected.
- Personalized progression suggestions, interactive maps with saved filters and collection progress, and pet genus filtering.
- Boss timers, favorites, and configurable alerts with a fixed-screen placement option.
- Optional Windows startup and update notifications from GitHub production releases or a chosen local update folder.

## Install or update

Download **Aion2Meter_1.0.0_x64-setup.exe** below and run it. Existing users can also select **Check for updates** in Companion Settings. Settings and saved encounters are preserved during upgrades. The installed app is named **Aion 2 Meter**.

Requires Windows 10 or 11 (64-bit), [Npcap](https://npcap.com/#download) for live capture, and Microsoft Edge WebView2. Setup downloads WebView2 if it is missing. Internet access is needed for character profiles, remote images, and GitHub updates.

Version 1.0.0 is a production release. Earlier versions can discover it automatically; future production releases with a higher version will appear through the same updater. Installation requires your choice. The `latest.json` asset is updater metadata and does not need to be opened manually.

## Current limitations

- The installer is unsigned, so Windows may display an unknown publisher or SmartScreen warning.
- Capture and profile coverage depend on the game messages and external services available. Missing data and game updates can affect results.
- Speciality selections are inferred from the latest matching recorded encounter, not confirmed current loadouts. Unknown selections remain marked as unknown. Description values may vary by game version.
- Map coverage follows the bundled dataset; incomplete Cube markers are excluded.
