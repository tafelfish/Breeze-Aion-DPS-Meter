# Breeze Aion DPS Meter 0.2.0 Preview

The first public preview combines the encounter meter and Companion in one Windows application.

## Highlights

- Live damage, healing, and damage taken with customizable player rows and class colors.
- Separate overlay and Companion windows with saved placement, size, and anchoring.
- Encounter logs with dungeon run grouping, skill breakdowns, timelines, CPM, HPM, and captured buff uptime.
- Character profiles, progression suggestions, maps, collectibles, boss timers, and notifications.
- Production release update checks through GitHub, alongside the existing local update folder.

## Installation

Download and run **Aion2Meter_0.2.0_x64-setup.exe**. Close the running meter normally first. The application is installed as **Aion 2 Meter** and preserves existing settings and encounter history on upgrade.

Requires Windows 10 or 11 x64 and a separate [Npcap installation](https://npcap.com/#download) for live capture. Setup installs WebView2 if needed. The installer is unsigned, so Windows may show an unknown publisher or SmartScreen warning.

## Preview limitations

- Capture and buff coverage depend on observed game messages. Missing or unidentified data remains incomplete.
- Character profile data may arrive later than combat data and depends on external service availability.
- Game updates can affect capture compatibility. Accuracy across all encounters and network configurations has not been verified.

## Updates

This release is a **prerelease**, not a production release. GitHub update checks ignore prereleases. Future production releases with a higher version will be offered in the app, with an overlay notification and an explicit **Install update** action. Local update packages remain supported.

The attached `latest.json` contains the installer size and SHA-256 used for verification. No source code, personal encounter logs, or development history is published in this repository.
